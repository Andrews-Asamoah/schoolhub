1. Credential store

Saves a test token in the OS credential store, reads it back, then deletes it.

2. Encrypted database

Opens a per-school, per-user SQLCipher file. The key lives in the credential store.

3. Sign in over Rust HTTP (including 2FA)

The API call is made by Rust, not the page. The token goes to the credential store.

4. Offline attendance slice

Records attendance into the encrypted database and the outbox in one transaction, then pushes to the mock server (pnpm --filter @schoolhub/desktop mock-server).
